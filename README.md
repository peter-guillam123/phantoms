# Phantoms

A compendium of short ghost stories, each in the voice of an invented
writer of roughly 1880–1925. The stories are not written yet. So far
there is a website with a biography of each writer and of the editor who
links them.

To see the site:

```bash
python3 build.py --serve
```

Then open http://localhost:8000.

- `content/` is what readers see.
- [personas/](personas/README.md) holds the working briefs: voice rules
  and what is real.
- [research/](research/README.md) holds the history behind them, how well
  it has been checked, and what is missing.
