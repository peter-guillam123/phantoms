# Phantoms

A compendium of short ghost stories, each in the voice of an invented
writer of roughly 1880–1925. Not built yet. So far there is:

- [The ten writers](personas/README.md): who they are, what a ghost is to
  each of them, and how each one writes.
- [Research notes](research/README.md): the real history behind them, how
  well it has been checked, and what is missing.
